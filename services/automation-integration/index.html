Small on purpose

A typical build is a Power Query model that refreshes, a VBA routine for a report the accountant already knows, or a PowerShell script for licence and mailbox reviews. Sometimes it is a form posting into a folder the site already uses.

The tool is sized to how often the job runs and to the person who will open it on a Monday. The handoff lists the steps, the file locations, and what to check when a refresh fails.
