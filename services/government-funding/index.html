A reviewable file

Reviewers score a project they can see: what will be bought or built, what it costs, and how the business will use it. The narrative and the budget need to name the same costs. When the story lists equipment and the budget lists consulting, the file comes back.

Completed files include multimillion-dollar awards, among them $4.5M+ for infrastructure and equipment. The next file is written from your project, your quotes, and the program guide in front of us.

Sequence

How it runs

    Eligibility

    Program rules, timing, and whether the project fits, before a draft starts. Quotes are gathered ahead of the deadline.

  2. 02

    One set of costs

    Narrative, budget, and quotes use the same line items. An internal owner is named for reviewer questions.

  3. 03

    Submit and report

    The package goes in before the deadline. When an award is made, claims follow the same scope.
